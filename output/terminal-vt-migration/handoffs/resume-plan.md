# M2 恢复执行安排

主线程：共享文档、真实 UI、版本绑定、性能采样、审查与报告。Coder：scripts/terminal-window-probe.swift 只读几何观测工具及其独立测试证据；不写 App 或共享状态。

1. 核对 App PID/可执行路径/哈希；外部 AX/CG 测量外框、内容根节点、终端节点及显示模式。无法读出 NSWindow 原生 contentView 时明确观测代理边界，不用截图像素代替。
2. 用 CUA 调整窗口，独立复测 900×560；亮暗、单栏/双栏留图。准备读取程序后请用户完成候选/取消/组合焦点与 VoiceOver 人工回执。
3. 主线程验证资源隐藏恢复、取消关闭、确认关闭、PID 回收；AX 与人工听读分别记录。
4. 核对旧/新 Release 的实际字体/格距、网格、视口和主题。只有条件可比才采 CPU/RSS 多轮；trace 成功也按可观测事件解释，不把 GPU 时间替代输入延迟。
5. 基线有效后提出预算，待用户确认。共享规范文档冻结后用 record_execution --repo --state 重跑受影响检查；后续只写排除于 revision 的证据、结构状态和日志。未判定项目继续阻断 M2 整体通过。

本轮不提交推送，默认旧后端、旧依赖和 M3 保持原状。已有 dirty 文件全部保留。
