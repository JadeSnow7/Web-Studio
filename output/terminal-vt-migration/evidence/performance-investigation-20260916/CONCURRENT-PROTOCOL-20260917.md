# 真实输入输出并发协议

沿用历史规范化副本，fresh App/PTY，134×45、13pt、深色、2×。每轮先两次20秒相同并发预热，每次reset并查DSR；正式前再次reset。child实际输出200行 OUTPUT seq=0..199，目标100ms；主线程经CUA真实键盘发送20行INPUT seq=0..19，Ctrl+j终结LF，目标间隔800ms。输入调度不从App启动计时，而从本轮start-loop事件被观察后开始；记录实际child接收时刻，CUA调度时间不作为输入显示延迟。

App累计CPU在23秒固定采样包络，启动后1秒发起20秒负载；输出结束后DSR查询至多1秒，必须位于CPU有效样本首末内。真实输入/输出/echo序列、完整字节hash、子进程CPU及DSR单列。AX每次输入后取状态是观测负荷的一部分，两端同协议；完成后保存最终画面。RSS仍只离散测量；不报告frame/GPU/presentation延迟。

先一组配对试采验证，排除于正式基线。之后6组交替配对，任何失败保留原因；不能把漏输入、错PID、晚回执或未完成窗口记为有效。不在基线期间编译/测试/profiler。计时包络以实际采样首末为准。
