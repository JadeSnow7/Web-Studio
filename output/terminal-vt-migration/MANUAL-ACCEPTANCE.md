起点：`2631e14`。只验收独立 VT 构建，生产默认仍是旧后端。实际构建路径、二进制哈希、系统版本、输入法、显示缩放与时间在每次现场记录中填写。未执行的项目为 `undetermined`，不沿用旧二进制的通过结果。

## 用户协助的中文输入法

主线程准备真实 VT 窗口和终端内的文本读取程序，避免将测试文本作为 shell 命令执行。使用用户现有中文输入法；不静默修改输入源配置。

1. 输入 `zhongwen`，观察预编辑文本是否可见，候选框是否靠近实际光标。
2. 用方向键或数字切换候选，回车提交，确认最终文本为所选中文且没有重复、遗漏或英文字母泄漏。
3. 再输入拼音后按 Escape，确认组合取消且未向应用提交残留文本。
4. 在组合中切换焦点再返回，记录组合保持或取消的实际行为及是否重复提交。
5. 在 900×560 内容区和左右分栏各重复一次，确认候选框未裁切、未漂移。

主线程保存 AX/窗口截图与接收程序的实际文本。候选 UI 的可见性和人工操作结果需明确记录；合成 NSTextInputClient 测试只记接口通过。

## 窗口和外观

- 以 `--minimum-window` 启动；记录实际内容区和外框尺寸，不能只凭启动参数判为 900×560。
- 默认窗口、最小内容区、左右分栏分别观察 Unicode、组合字符、Emoji、真彩色、光标和选区。
- 保存真实亮/暗 PNG，记录 backing scale。只有本机 2× 时，其他实际缩放仍未通过。
- 检查减少动态效果、非闪动光标、增加对比度的实时变化，测试后恢复原设置。

## VoiceOver、焦点和关闭

- 用户使用 VoiceOver 进入终端，读取多行输出和选区，移动到地址栏/命令面板后回到终端，记录朗读文本、导航和输入结果。
- 记录 shell PID；切换资源、分栏、隐藏再显示、切换主题，核实历史、选区和焦点。
- 关闭时先取消，再确认，分别检查会话存活与所属进程回收；保留一个无关进程作对照。
- 回归 ⌘L、⌘K、网页和显式 Agent 读取预览，不发送 Agent 请求。
