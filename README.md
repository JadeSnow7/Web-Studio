# Web Studio

A macOS workspace for terminal, browser, and agent sessions.

## Current state

Initial macOS SwiftUI application generated by Xcode, with Swift Testing and XCTest UI test targets. Browser, terminal, Agent Runtime, and Rust integration are planned and are not implemented yet.

## Development

Open `Web Studio.xcodeproj` in Xcode, select the `Web Studio` scheme and `My Mac`, then run.

Command-line build without distribution signing:

```sh
xcodebuild -project "Web Studio.xcodeproj" -scheme "Web Studio" -configuration Debug -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build
```
