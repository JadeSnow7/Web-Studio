# W1 本轮执行协议

日期：2026-09-17。本轮从冻结源码生成 control/candidate，唯一候选因素是字体帧内复用。历史数据仅用于提出假设。

1. 原补丁 clean apply、当前源码与冻结版逐字节比对；默认后端不变。
2. 分别执行 Release arm64/coverage off 构建、Metal smoke 与既有九幅 BGRA 对比。零差异只支持这些离屏场景。
3. App 八场景要求六组交替配对，使用同一批新构建、同一字号网格、同一历史/AX 协议，原始失败与反向值全部保留。每一场景独立给状态，没执行不能并入通过。
4. 离屏 Unicode 诊断只解释 renderer 成本。其固定 100 提交、GPU completion wait 与真实 App 帧合并不同；不能作为 App 八场景或 input-to-present 替代。
5. GUI 须实际验证中文 IME、组合宽字符/Emoji、选区、主题、缩放、隐藏恢复、双栏 resize 与资源压力；缺项维持未判定。
6. 采集与构建、其他压力串行。采样时保留已有用户 Apps；采集后台上下文，干扰严重的运行标异常且保留，不按收益方向筛选。

采用：重复目标收益且关键场景无可重复退化、完整 GUI/生命周期通过。当前预算仍 proposed，不新增凑结果通过线。没有收益或正确性退化撤回候选；证据缺口记继续调查。仅候选隔离路径可写，生产文件仍未采用。

尚未测得的可靠 input-to-present、GPU 执行、内存峰值保持 null。
