# B1 实施 Spec

版本：B1-SPEC-2，2026-09-17。产品尚未验收；当前实施阶段与执行回执见 task-summary.md。

## 来源与范围

产品输入冻结为 [B-Plan v1](inputs/B-Plan-v1.md)，与原方案逐字一致。此前「准备实现」阶段已交付合同与冻结基线；用户现已要求「开始执行」。本轮依照既有合同启动 P0 并沿依赖推进 P1–P4，实现与验证分别记录，未满足阶段不标完成。

采用附件推荐默认值作为实施准备基线：自有文案简中；一空间一个窗口宿主；保存本地配置；重启不启动 Shell/SSH/AI；问答仅在空间载入期间保留；单次请求不带隐式历史；最多左右双视图。用户已要求按准备包开始执行；沿用这些默认值，不扩展提交或发布授权。

目标是完成「创建工作空间→添加网页和终端→并排→读取、审阅并发送资料→切换另一空间→返回原布局与草稿→下次启动恢复配置」。同次应用运行保留运行时；退出后仅恢复配置。

产品目标和可观察规则以本文及其引用的冻结输入为任务契约；实现方法见 [ARCHITECTURE.md](ARCHITECTURE.md)，验证输入与判据见 [ACCEPTANCE.md](ACCEPTANCE.md)。结构化索引、执行状态与证据关系由 [task-state.json](task-state.json) 维护。Swift 类型和协议在实现后成为接口字段权威，不另建手写字段镜像。

## 不变量

1. 工作空间承接分组；不增加项目/工作空间/任务组三层。首次启动的临时空间不跨退出保存；新建命名空间默认自动保存。空空间不自动产生网页。
2. 每个空间独立拥有资源、常用入口、布局及问答内存；每个窗口可载入多个空间但只显示一个。同一空间最多一个宿主；点选他窗空间仅激活既有窗口。
3. 切换空间保留原运行时与请求，先撤销地址编辑、关闭临时命令面板；其他表单草稿留存或显式处理。回调归属不得取决于当前前台空间。
4. 收起视图只解除引用；结束会话保留资源描述；关闭资源释放一次运行时；关闭空间/窗口/应用先汇总影响、处理保存，再等待清理。关闭任务可重入但释放不能重复。
5. 配置只含空间元信息、资源描述、入口、布局、焦点和面板偏好；AI 正文、快照、进程输出、密钥不写入空间文件。WebKit 沿用共享数据存储，临时空间不代表隐私隔离。
6. 配置恢复、资源搜索和仅打开来源选择器均无启动或读取正文副作用。可见网页按需载入；Shell/SSH 必须明确启动/连接。
7. 选择变化使旧预览失配；失败来源必须重读或明确移除。发送固定问题、快照及 Provider 配置；用原快照重试不重读。每空间最多一个请求；新问题保留旧问题及未发送草稿。
8. 资源实例、问题和请求代次区分迟到回调；终端重启生成新实例身份。复制入口只复制目的地，不移动活动运行时或快照。
9. 保留现有终端后端和快捷键、原生视觉语言、无常驻内容标题栏。性能/VT 路线保持独立，本次不宣称性能改善。

## 异常与非目标

目录失效保留配置并要求重选；不静默回退目录。未知新 schema 只读保护；损坏主文件保留原件并尝试有效备份；无备份隔离该空间。重复 ID 拒绝冲突项并报告；坏布局修复引用并提示，其他有效资源可用。

写入失败保留内存配置与错误，支持重试。关闭前支持重试、取消、不保存并关闭；进入不可逆清理后明确「正在关闭」，不假装能恢复已结束进程。无效地址和未闭合输入必须产生明确验证结果。

B1 不提供永久删除、后台守护进程、跨退出运行时/页面表单恢复、问答长期保存、连续对话、账号隔离、自动启动命令、运行时跨窗口迁移、执行型 Agent 或团队同步。既有分组没有磁盘来源，不能承诺升级后恢复旧内存。

## 实施与证据边界

500ms 保存合并是初始工程参数，测量写入次数及主线程负担后校准；窄窗断点由 900×560、常用笔记本和大窗口原型决定。P0 评审完成后再启动 P1；P1 所有权合同稳定后进入 P2/P3；共享路径串行交给同一 coder。

当前没有阻断 P0 实施的用户决定。P0 视觉细化、Swift 签名和 schema 字段属于下游实施设计；改变上述用户行为时才更新 Spec。P4 的真实 SSH 目标和 Provider 配置如不可用，对应验证记 undetermined，不用离线模拟代替。

证据绑定内容指纹与版本；模型/集成/真实 GUI 各自判定。准备检查通过只证明实施资料就绪。B1 整体验收仍需 SC-P0–SC-P4 全部满足；commit、push、merge、deploy 均未授权。
