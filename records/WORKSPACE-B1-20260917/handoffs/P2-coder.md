## 最小完整结果

- 纯 Codable 配置：schemaVersion、workspaceID、name、archived、revision、资源目的地/自定义名/顺序、入口、paneID/resourceID/ratio/focus、面板偏好。禁止序列化 ResourceRecord 全对象；运行态、错误日志、进程输出、问题/快照/messages、Provider 密钥均不属于空间文件。
- Repository 端口支持目录、读取、保存和备份恢复，区分不存在/损坏/未知新 schema/冲突/无权限。注入配置根目录与故障端口，测试和 GUI 验收只操作独立测试目录。默认配置目录通过系统 Application Support 取得。
- 保存任务离开主线程；配置 generation 绑定回执，500ms 合并只作初始参数。关闭等待排队写入；旧写完成不清除新脏状态。一个空间一个有效原子文件，先校验临时写入，再保留上一有效备份，替换主文件；失败保留原件和可见错误。
- 未知新 schema 不覆盖；损坏主文件不删除，显式选用有效备份并保留原件；无有效备份则隔离。重复ID拒绝冲突，坏pane引用修复并告知，不抛弃所有有效资源。多实例写入用预期revision/锁保护或明确冲突拒绝，禁止最后写者静默覆盖。
- 目录列举、搜索、恢复、来源选择器只触碰描述，不创建 Shell/SSH session、不调用 Provider。可见网页才懒加载。明确启动需验证目录，非法/失效目录保持原描述并显示错误；重试启动幂等，结束后资源保留，再次启动换实例身份。
- 保存状态持续可见（保存中、已保存、尚未保存/错误），绝不能用临时 toast 代替失败状态。关闭失败提供重试、取消、不保存关闭；不保存关闭必须回退为最后成功保存描述，不能清除错误后偷偷保存。归档是关闭运行时并持久化目录状态；重启不能自动恢复归档为打开。
