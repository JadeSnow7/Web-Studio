# P3b：独立问题的原生入口

> 文档状态标注（2026-09-26）：本文保留原日期、原版本的派发约束与交接记录，不是当前待执行清单。当前实现、后续修复和验收缺口见 [状态总览](../../../STATUS.md)。

在 P2c/P3a 核心测试冻结完成后派发给 coder_p0_repair。独占 AgentViews.swift；仅为稳定问题顺序/预览确认状态的必要只读端口可修改 AgentController.swift，新增相应 WorkspaceQuestionTests.swift 用例。暂不修改 ContentView / Registry / WindowCoordinator / Session / ResourceModel，另一 coder 同时负责保存与恢复。保留他人修改，不提交，不做全文件格式化。

- 新建问题调用 newQuestion，保留旧问题；可按创建顺序从菜单选择旧问题，标题取首条问题或未发送草稿的可读摘要，空题显示“新问题”。不能用无序字典或 UUID 排序当历史顺序。
- 预览面板明确提供“确认这些资料”动作，展示确认/需重新确认；仅读取不得允许发送。错误来源有重新读取或明确移除入口。选择变化自动失效沿用核心。
- 详情展示资源 ID、运行实例 ID（有值时）、时间、范围和截断、原请求问题与 Provider 配置；不重新读取来源。当前题以外的活跃请求有可读状态、跳回原题和停止动作，不把空间级请求状态误当当前题请求。
- 来源读取/预览面板关闭只收起 UI；新问题与切题不清空旧题、不取消已发送请求。面板切换目标按既有 model 锁处理，不在 UI 的异步回调使用另一个当前空间。
- 所有本文件自有文案简中；保留 API、Codex CLI、模型/URL 等专名。不要触发登录/请求、读取密钥或外部真实 Provider。
- 为原生自动化提供可读 accessibilityLabel 和稳定 identifier。窄窗保留编辑框和主要入口；无需另造视觉体系。
